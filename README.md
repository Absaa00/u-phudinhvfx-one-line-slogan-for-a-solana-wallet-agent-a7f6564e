# One-Line Slogan for a Solana Wallet Agent

Entry for [make.fun](https://make.fun/competitions/u-phudinhvfx-one-line-slogan-for-a-solana-wallet-agent-a7f6564e) — built with make.fun.

## The slogan

> Your keys. Your SOL. Your rules. A wallet as fast as Solana itself.

Thirteen words, one line. Self-custody first ("your keys, your SOL, your rules"),
then the Solana promise: a wallet as fast as the chain it lives on.

## Run

```sh
python3 main.py
```

Writes the single slogan line to `/output/entry.txt`.
Deterministic: every run produces the exact same bytes.
No network, no dependencies beyond the Python standard library.
